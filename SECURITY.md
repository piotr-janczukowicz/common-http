# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately with
[GitHub's private vulnerability reporting](https://github.com/piotr-janczukowicz/common-http/security/advisories/new).

Include the affected version, a description of the problem and, if you can, steps to reproduce it. You will get an
answer within a week, and the fix is released before the details are published.
